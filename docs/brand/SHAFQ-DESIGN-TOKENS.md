# SHAFQ — Design Tokens & Color System

## Official Color Palette
Centralized in `apps/mobile/src/constants/theme.ts`:

| Token | Hexadecimal | Usage |
|---|---|---|
| `primary` | `#19A9CC` | Brand Primary (active controls, buttons, highlights) |
| `primaryDark` | `#087EA4` | Headings, emphasized text, deep branding elements |
| `primaryLight` | `#DDF6FC` | Pale cyan brand surfaces and selected states |
| `secondary` | `#65D7E8` | Supporting interactive elements |
| `background` | `#F4FCFE` | Main application background |
| `surface` | `#FFFFFF` | Cards, modals, elevated white surfaces |
| `textPrimary` | `#16485C` | Main readable text |
| `textSecondary` | `#688795` | Secondary labels, captions, metadata |
| `success` | `#10b981` | Success states, completed orders |
| `warning` | `#f59e0b` | Pending states, alerts |
| `error` | `#ef4444` | Errors, cancellation states |

## Typography
- **Primary Arabic Script**: System UI / Sans-serif optimized for Arabic RTL display.
- **Font Scale**: Consistent type hierarchy across headings, body text, and captions.
