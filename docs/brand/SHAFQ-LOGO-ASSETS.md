# SHAFQ — Logo Assets & Specifications

## Asset Directory
All production logo and brand assets reside in:
`apps/mobile/assets/branding/`

## Asset Inventory
1. **`shafaq-emblem.svg` / `shafaq-emblem.png`**: Standalone circular medical dawn emblem. Used for launcher icons, adaptive foregrounds, and compact badges.
2. **`shafaq-logo-primary.svg`**: Full primary logo combining the custom emblem and the Arabic wordmark **شَفَق**.
3. **`shafaq-icon-1024.png`**: High-resolution 1024×1024 master icon for app stores and Expo native icon configuration.
4. **`shafaq-emblem-monochrome.svg` / `shafaq-emblem-monochrome.png`**: Monochrome version for dynamic theming and accessibility.
5. **`shafaq-emblem-white.svg` / `shafaq-emblem-white.png`**: High-contrast white version for colored surfaces.
6. **`shafaq-splash-logo.png`**: Splash screen logo asset.
